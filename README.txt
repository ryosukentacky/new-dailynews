経済ニュース学習カード（2026-10-28書き出し資料）

使い方
ZIPを展開し、index.htmlをブラウザで開いてください。
GitHub Pagesに掲載する際は、展開したindex.htmlを使用します。
GitHubへのアップロード・公開はまだ行っていません。

収録
・ニュース解説22メッセージを、見出しに沿って93件に分割。
・元の解説は省略・要約・書き換えせず、カードの書き出し原文と埋め込みデータに保持。
・source_backup.htmlはアップロードされた元ファイルと同一バイトの完全バックアップです。
・アップロード相談などの会話は通常のカード一覧には掲載していません。
・導入や分類表は各回の最初のカードの「この回の導入・分類」に収録。
・各回のまとめ問題や復習は、その回の最後のカードに収録。

機能
・番号と記事名のプルダウンによる直接移動。
・検索、日付、カテゴリ、お気に入り、未学習の絞り込み。
・前後ボタンと記事位置スライダー。
・原文に存在するA/B/C/Dの表示切り替え、全文、書き出し原文。
・原文にA/B/C/Dの独立した区分がないカードは「全文」で閲覧。
・元の設定・数式に基づく操作用スライダー23個。
・元の問題の解答開閉、ラジオ選択、正誤表示。
・元のSVG図解3点、元の数値データを使用した棒グラフ5点と対応する数値表。
・操作と回答はページを閉じるまで保持、お気に入りと学習済みはブラウザに保存。
・横幅に応じた表示調整。

原文と補完の区別
後半7回の35問は、書き出しでは選択肢が連結され、正解データがありませんでした。
問題文と選択肢は一文字も変更せず分割し、正解番号を元の解説本文から判断して追加しています。
当該問題群には補完であることを明記しています。新しい問題や解説本文は作成していません。
専用部品の表示コードは、限定した構文を解釈して通常のHTML部品に変換しています。
コードを見たい場合は「書き出し原文」で確認できます。

画像と原資料の限界
記事写真の実データはこの書き出しに見当たりません。写真の依頼記述から画像を捏造していません。
SVG図解とグラフは収録していますが、記事写真がすべて復元されたものではありません。
元資料には「国際ニュース8本」とありますが、その回の独立した記事見出しは7件です。
不足する記事を新たに作成せず、残っている解説をそのまま保存しています。
ニュースの事実関係や将来予測、日付の表記は元資料のままです。独立した最新情報の検証は行っていません。
